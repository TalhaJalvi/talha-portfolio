Jetpack Compose Project Setup: Android Studio, Kotlin & Gradle

This guide shows the modern way to create a Jetpack Compose project and add Compose to an existing Android app. For new projects, Android Studio's Empty Activity template is the simplest path because it configures Compose for you.

2026 setup note: with Kotlin 2.0 and newer, the Compose compiler is configured through the Kotlin Compose Compiler Gradle plugin. Compose libraries are best managed with the official Compose BOM so compatible library versions stay aligned.

1. Create a New Compose App

  1. Open Android Studio and choose New Project.
  2. Select Empty Activity.
  3. Use Kotlin and choose the minimum SDK needed by your app.
  4. Finish the wizard and let Gradle sync.

2. Minimal Compose Activity

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            MaterialTheme {
                Text("Hello Compose")
            }
        }
    }
}

3. Enable Compose in an Existing Project

android {
    buildFeatures {
        compose = true
    }
}

4. Compose Compiler Plugin

For Kotlin 2.0+, use the org.jetbrains.kotlin.plugin.compose Gradle plugin and keep its version aligned with your Kotlin version. This replaces the older pattern of manually setting a Compose compiler extension version.

5. Use the Compose BOM

The Compose Bill of Materials keeps Compose libraries on compatible versions. As of September 2026, Android Developers lists the stable Compose BOM as 2026.08.00.

dependencies {
    val composeBom = platform("androidx.compose:compose-bom:2026.08.00")
    implementation(composeBom)
    androidTestImplementation(composeBom)

    implementation("androidx.compose.material3:material3")
    implementation("androidx.compose.ui:ui")
    implementation("androidx.compose.ui:ui-tooling-preview")
    debugImplementation("androidx.compose.ui:ui-tooling")
}

6. Verify the Setup with a Preview

@Composable
fun Greeting(name: String) {
    Text("Hello, $name!")
}

@Preview(showBackground = true)
@Composable
fun GreetingPreview() {
    Greeting("Compose")
}

7. Common Setup Problems

  • Compiler mismatch: on Kotlin 2.0+, use the Compose Compiler Gradle plugin that matches Kotlin.
  • Unresolved imports: verify the BOM and the specific Compose libraries your code uses.
  • Preview not rendering: include preview and tooling dependencies.
  • SDK compatibility: newer Compose releases can require newer compile SDK and Android Gradle Plugin versions.
