super in Kotlin: Parent Methods, Properties & Constructors

super in Kotlin is used inside a subclass to access an implementation from its parent class or a specific super-interface. It is most useful when you override behavior but still want to reuse part of the parent implementation.

Quick answer: use super.method() or super.property to access parent behavior. Parent constructors are invoked in the inheritance declaration, for example class Jet(name: String) : Aircraft(name).

1. Calling a Parent Method with super

open class Aircraft {
    open fun startEngine() {
        println("Parent engine checks")
    }
}

class Jet : Aircraft() {
    override fun startEngine() {
        super.startEngine()
        println("Jet-specific checks")
    }
}

The override extends the parent behavior instead of replacing it completely.

2. Accessing an Overridden Parent Property

open class Aircraft {
    open val type: String = "Aircraft"
}

class Jet : Aircraft() {
    override val type: String = "Jet"

    fun printTypes() {
        println(super.type) // Aircraft
        println(type)       // Jet
    }
}

3. Calling a Parent Constructor

Kotlin does not call a primary parent constructor with Java-style super(...) syntax. Instead, arguments are passed after the parent type in the class declaration:

open class Aircraft(val model: String)

class Jet(model: String, val maxSpeed: Int) : Aircraft(model)

fun main() {
    val jet = Jet("F-16", 1500)
    println(jet.model)
}

Inside a secondary constructor, constructor delegation still follows Kotlin's this(...) and inheritance rules rather than Java syntax copied directly into Kotlin.

4. Choosing a Specific Interface Implementation

If multiple supertypes provide the same function, Kotlin lets you choose one explicitly with super<Type>:

interface Logger {
    fun log() = println("Logger")
}

interface Tracker {
    fun log() = println("Tracker")
}

class Analytics : Logger, Tracker {
    override fun log() {
        super<Logger>.log()
        super<Tracker>.log()
    }
}

6. Common Interview Questions

  • What does super do in Kotlin? It accesses a parent implementation from a subclass.
  • Can super access an overridden property? Yes, for example super.name.
  • How do you call a parent constructor? Pass constructor arguments in the inheritance declaration, such as : Parent(arg).
  • What is super<Interface>? It selects a specific interface implementation when multiple supertypes provide the same member.
