Sequential Agent Workflows

Sequential workflows are appropriate when tasks have a natural dependency chain: extract → validate → enrich → generate.

Prefer typed state

Pass structured intermediate outputs rather than copying free-form prose between every step.

Add validation gates

Before an expensive downstream step, validate that the previous stage produced sufficient data.

Why this can beat a fully autonomous agent

When the order is known in advance, deterministic orchestration is easier to test and cheaper to run.
