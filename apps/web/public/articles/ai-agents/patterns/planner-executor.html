Planner-Executor Agent Architecture

A planner decomposes a goal into tasks; one or more executors perform them. The pattern is useful when a complex request benefits from explicit decomposition before action.

Make plans structured

Represent task ID, objective, dependencies, required tools, and completion criteria. Free-form plans are difficult to validate or resume.

Allow controlled replanning

Execution will discover missing information. Replanning should update the remaining plan rather than blindly restarting the whole run.

Do not plan trivial work

Planning adds model calls and latency. For a one-tool request, the best plan is often to call the tool directly.
