MCP Tools, Resources & Prompts: Core Capabilities Explained

A practical map of the capabilities an MCP server can expose and a client can consume, updated for the 2026-07-28 specification.

What are MCP core capabilities?

Model Context Protocol gives clients and servers a common way to describe capabilities such as tools, resources, and prompts. Tools represent actions, resources expose retrievable context, and prompts provide reusable prompt templates. The protocol also defines supporting behavior such as schemas, elicitation, completion, pagination, progress, cancellation and caching.

ResourcesRead somethingRepository file, customer record, schema, documentation

Key 2026 changes

The current protocol makes list/read results cacheable, adopts full JSON Schema 2020-12 for tool input/output schemas, restructures server-to-client interactions around Multi Round-Trip Requests, and deprecates roots, sampling and logging for new implementations. Deprecated features may still exist during their policy window, but new implementations should follow current replacements and specification guidance.
