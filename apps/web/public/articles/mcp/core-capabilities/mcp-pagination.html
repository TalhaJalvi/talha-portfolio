MCP Pagination

Large MCP catalogs should not be returned in one unbounded response. Pagination lets list methods return a page plus a cursor that the client can use to fetch more results.

Client responsibilities

  • Stop when no next cursor is returned.
  • Set a maximum-page guard to avoid accidental infinite loops.
  • Treat cursors as opaque unless the server explicitly documents otherwise.
  • Handle invalid or expired cursors gracefully.

Pagination and caching

The 2026 specification also adds cache hints to list results. Clients should respect the server's freshness guidance while preserving correct page ordering and cursor semantics.
