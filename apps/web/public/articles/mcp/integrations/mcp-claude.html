MCP with Claude and Anthropic

Anthropic supports MCP across several surfaces: Claude Code can configure MCP servers, Claude.ai can use MCP connectors, Claude Desktop supports server integrations, and Anthropic documents an MCP connector for remote MCP use from the Messages API.

Claude Code

The CLI includes claude mcp for configuring servers. This is useful for developer workflows where MCP tools should be available directly from the coding agent.

Claude API

The API-side connector pattern lets Anthropic's service connect to a publicly reachable remote MCP server without your application implementing a separate MCP client for those calls. Check current feature/transport support before choosing this path because API connector capabilities can differ from local Claude clients.

Portability note

Keep server tools and schemas model-neutral. Host-specific configuration belongs in deployment docs rather than in the core tool implementation.
