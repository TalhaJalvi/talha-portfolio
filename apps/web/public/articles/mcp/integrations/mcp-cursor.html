MCP in Cursor

Cursor can connect external tools/data through MCP. It currently supports stdio, Streamable HTTP, and legacy SSE, plus tools, prompts, resources, elicitation, roots compatibility, and MCP Apps.

Configuration locations

Project-specific servers can live in .cursor/mcp.json; global configuration can live under the user's Cursor configuration. The UI also supports marketplace installation.

Safe secret interpolation

Use environment interpolation rather than committing raw API keys into mcp.json.

Approvals

Cursor asks for MCP tool approval by default, subject to the current run/review mode and configured policies.
