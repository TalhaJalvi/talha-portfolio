MCP Streamable HTTP

Streamable HTTP is the modern network transport for MCP servers you deploy. The 2026-07-28 protocol makes the core stateless, allowing requests to land on any compatible instance behind normal HTTP infrastructure.

Production advantages

  • Works with gateways, TLS, load balancers, and observability.
  • Authorization can use standard HTTP headers.
  • Mcp-Method and Mcp-Name headers support routing and metering.
  • Horizontal scaling no longer requires protocol session affinity for the modern core.

Client example

from mcp.client import Client

async with Client("https://mcp.example.com/mcp") as client:
    tools = await client.list_tools()

Operational requirements

Use TLS, explicit timeouts, bounded retries, request-size limits, and authentication. Treat it as a real internet-facing API surface.

Legacy SSE is not the preferred transport for new implementations.
