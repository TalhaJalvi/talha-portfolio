Long-Running MCP Operations

If work lasts minutes or hours, holding an ordinary request open is fragile. The official Tasks extension lets a server return a durable task handle and allows the client to poll progress and retrieve the eventual result.

Good task use cases

  • CI pipelines.
  • Cloud deployments.
  • Batch processing.
  • Human approval gates.
  • External asynchronous APIs.

Durable state

Store task status/results outside a single web process so a restart or load-balanced request does not lose progress.
