How to Use MCP Inspector

MCP Inspector is an interactive test client for exercising a server without first wiring it into a full AI host.

Python shortcut

uv run mcp dev server.py

The Python SDK starts the server and opens Inspector. Because Inspector is a Node.js app, npx must be available.

Direct stdio use

npx @modelcontextprotocol/inspector python server.py

Inspector launches the command, connects over stdio, lists exposed capabilities, and builds forms from tool schemas.

What to inspect

  • Tool names/descriptions and required fields.
  • Valid and invalid arguments.
  • Structured output shape.
  • Resource URIs and templates.
  • Prompts and prompt arguments.
  • Error behavior and latency.
Inspector is excellent for deterministic protocol testing; it does not replace automated tests or agent-level evaluations.
