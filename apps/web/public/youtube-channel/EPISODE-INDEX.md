## Recommended production batches

1. Record Episodes 1–4, then publish Episode 1 only after Episode 2 is edited and scheduled.
2. Use audience questions to clarify Episodes 5–8 without changing their learning outcomes.
3. Record Episodes 9–13 after testing every demonstration in the same clean environment used on camera.
4. Build Episodes 14–16 as public GitHub projects before recording their walkthroughs.

## Definition of ready to publish

- The opening result appears within 15–25 seconds.
- Every command and code sample has been rerun in a clean environment.
- Private paths, accounts, keys, and notifications are hidden.
- The thumbnail remains readable at phone size.
- The description links the source code, references, next lesson, and playlist.
- The end screen and pinned comment point to exactly one next lesson.
- Captions and on-screen code have been checked for spelling and syntax.
