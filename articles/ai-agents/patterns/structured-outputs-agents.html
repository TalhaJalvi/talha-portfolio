Structured Outputs for Agents

Free-form text is ideal for human communication but fragile for software control flow. Use typed outputs whenever the next step is code.

Good uses

  • Routing decisions.
  • Plans and task lists.
  • Classification and confidence fields.
  • Tool result normalization.
  • Final machine-consumed payloads.

Validate before acting

A successful model response still needs schema validation and domain checks. A syntactically valid amount of -500 may still be invalid business input.
