Design principle

Anthropic's agent guidance emphasizes starting with the simplest workflow that solves the problem and adding autonomy only when it creates measurable value. OpenAI's Agents SDK distinguishes manager-style “agents as tools” from handoffs, while LangGraph distinguishes predetermined workflows from dynamic agents and provides persistence for stateful execution.
