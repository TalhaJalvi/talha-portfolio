Agent Memory Explained

Agent memory is the system that preserves useful state across steps or conversations. It is not simply “send the entire chat forever.”

Three useful layers

  • Working state: data needed during the current run.
  • Conversation memory: recent messages and summaries across turns.
  • Long-term memory: durable facts, preferences, artifacts, or records stored outside the prompt.

Store, retrieve, compress

Good memory systems decide what to save, when to retrieve it, and how to compress it before model use. More memory is not automatically better.

Security

Long-term memory can become sensitive user data. Apply retention, access controls, deletion, and tenant separation just like any other datastore.
