Key 2026 changes

The current protocol makes list/read results cacheable, adopts full JSON Schema 2020-12 for tool input/output schemas, restructures server-to-client interactions around Multi Round-Trip Requests, and deprecates roots, sampling, and logging for new implementations. Those deprecated features still work during the policy window, but new systems should use the documented replacements.
