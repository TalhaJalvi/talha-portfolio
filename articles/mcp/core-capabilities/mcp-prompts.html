MCP Prompts Explained

MCP prompts allow a server to publish reusable prompt templates that clients can discover and request. They are useful when the server knows domain-specific workflows that should be exposed as guided entry points.

What prompts are good for

A database server might expose “investigate slow query,” while a Git server might expose “review recent changes.” The prompt can define arguments and return message content that the host incorporates into its interaction.

Prompts are not tools

A prompt suggests or structures model behavior. A tool performs an action. A prompt may lead the model to call tools, but it is not itself an execution capability.

Prompts can evolve independently

Keeping domain-specific prompt templates on the server can make them reusable across hosts and easier to version alongside the capabilities they reference.
