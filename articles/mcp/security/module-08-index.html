Security baseline

For HTTP authorization, MCP builds on OAuth and requires careful token audience validation. Access tokens belong in authorization headers, not query strings. A server wrapping an upstream API must not blindly pass the inbound MCP token through to that upstream service. The 2026 spec also adds authorization hardening such as issuer validation.
