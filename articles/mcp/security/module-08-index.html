Stop cross-tenant data leaks

A SaaS MCP server exposes get_invoice(invoice_id). The dangerous implementation fetches by invoice ID only. The safe implementation scopes every lookup to the authenticated tenant.

# unsafe
invoice = db.invoice.get(invoice_id)

# safer
invoice = db.invoice.find_one(
    id=invoice_id,
    tenant_id=context.tenant_id
)
if not invoice:
    raise NotFound()
