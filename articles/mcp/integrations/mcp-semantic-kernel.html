MCP with Semantic Kernel

Semantic Kernel can import capabilities from MCP servers as plugins. Current Microsoft docs describe MCPStdioPlugin and MCPStreamableHttpPlugin for local and HTTP MCP connections.

Python setup

pip install "semantic-kernel[mcp]"

Local server

Configure the command/arguments and environment for a stdio server, then add the MCP plugin to the kernel or agent.

Remote server

Use the Streamable HTTP plugin for modern remote servers and supply the appropriate authentication configuration.

Keep protocol code separate

Your MCP server should not need to know it is being consumed by Semantic Kernel. Framework-specific adaptation belongs on the client side.
