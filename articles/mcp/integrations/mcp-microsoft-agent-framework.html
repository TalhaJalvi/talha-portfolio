MCP with Microsoft Agent Framework

Microsoft Agent Framework supports MCP server tools for production-oriented agents and documents integrations across C#, Python, and Go.

Core pattern

Create an MCP client, retrieve available server tools, adapt those tools to the framework's function/tool abstraction, and attach them to the agent.

Third-party server warning

Microsoft's guidance explicitly reminds developers that prompts/data can be sent to non-Microsoft services when third-party MCP servers are connected. Review credentials and data boundaries before use.

Agents as MCP servers

The framework also documents exposing agent capabilities through MCP, useful when another compatible host should consume your agent as a reusable service boundary.
