The Official MCP Registry

The official MCP Registry is a community-driven registry service for MCP server metadata and discovery. It does not replace package hosting: local server artifacts remain in package registries such as npm or PyPI, while the MCP Registry records/verifies server metadata.

Why a registry helps

Without a common registry, clients and users discover servers through disconnected marketplaces and lists. A shared metadata layer can support search, verification, version discovery, and downstream catalogs.

Preview status

The registry documentation currently labels the Registry as preview, so integrations should tolerate schema/process changes until general availability.
