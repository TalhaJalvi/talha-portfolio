Interactive UI Inside an AI Conversation

Not every agent interaction belongs in prose. A date picker, sortable table, chart, or confirmation form may communicate state more accurately than another model turn.

When UI helps

  • Complex structured input.
  • Visual data comparison.
  • Multi-select choices.
  • Reviewing a destructive action before approval.
  • Dashboards with drill-down.

When text is better

Do not build an app view for a two-field question or a one-line result. UI adds implementation and security complexity.

Accessibility and fallback

Build keyboard-accessible, readable interfaces and keep equivalent standard MCP output for hosts without Apps support.
