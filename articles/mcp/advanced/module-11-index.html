Official extension ecosystem

MCP's extension framework is now first-class. Current official extensions include MCP Apps for interactive UI, Tasks for durable long-running work, OAuth Client Credentials for machine-to-machine access, and Enterprise-Managed Authorization for centralized enterprise identity policy. Extensions are opt-in and use negotiated identifiers rather than silently changing core behavior.
