2026 production shift

MCP 2026-07-28 removes the core handshake/session requirement. Requests are self-describing and can land on different instances behind a round-robin load balancer. Streamable HTTP also carries method/tool names in headers, while list responses provide cache guidance. Those changes make standard cloud infrastructure a much better fit for MCP.
