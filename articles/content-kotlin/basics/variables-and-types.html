Variables & Data Types in Kotlin

Variables are the building blocks of any programming language. They are used to store data that can be manipulated and accessed throughout a program. Kotlin provides a modern, type-safe approach to variables and data types, helping developers write safer and more expressive code.

1. Why Variables Are Needed

Variables are needed because programs usually require:

  • Storing Data: To hold numbers, text, or objects that can change over time.
  • Data Manipulation: To perform calculations, string operations, or logic based on stored values.
  • Code Reusability: Instead of hardcoding values, variables allow flexible and maintainable code.

How Variables Store Data Internally in Kotlin

Kotlin runs on the JVM, so variables are stored either in the stack or heap depending on their type. Understanding this helps you write more efficient and safe code.

1. Primitive Types

Primitive types like Int, Double, and Boolean store their values directly in the stack for fast access.

val age: Int = 25
var temperature: Double = 36.6

2. Reference / Object Types

Reference types like String, List, or custom classes store a reference in the stack, pointing to the actual object in the heap.

val name: String = "Kotlin"
val numbers: List = listOf(1, 2, 3)

3. Nullable Types

Kotlin enforces null-safety. Nullable references can hold null or point to a heap object.

var nickname: String? = null
nickname = "Kotliner"

4. Memory Layout Diagram

Stack (Fast, LIFO)

  • age: 25
  • temperature: 36.6
  • name → reference → points to heap
  • numbers → reference → points to heap
  • nickname → null / reference → heap

Heap (Managed, GC)

  • "Kotlin" (String object)
  • List object [1, 2, 3]
  • "Kotliner" (String object)

5. Key Points

  • Primitives are stored in the stack → very fast.
  • Objects are stored in the heap → accessed via references in the stack.
  • Kotlin ensures null-safety at compile time for nullable types.
  • Heap memory is managed by the JVM garbage collector.

When you assign a value to a variable, the compiler allocates the appropriate memory, and the JVM keeps track of the type. Kotlin also adds null-safety at compile-time, preventing many runtime errors common in Java.

3. How to Define Variables in Kotlin

Kotlin uses two keywords for variables:

  • val — Immutable variable (cannot be reassigned, similar to final in Java).
  • var — Mutable variable (can be reassigned).

Syntax:

val name: String = "Kotlin"   // Immutable
var age: Int = 25               // Mutable

Kotlin also supports type inference, so you can omit the type if it can be inferred from the value:

val city = "London"   // Kotlin infers String
var score = 100             // Kotlin infers Int

Example Program

fun main() {
    val language: String = "Kotlin"      // Immutable variable
    var version: Double = 1.8            // Mutable variable
    
    println("Language: $language")
    println("Version: $version")
    
    // Reassign mutable variable
    version = 2.0
    println("Updated Version: $version")
    
    // Nullable variable
    var nickname: String? = null
    println("Nickname: $nickname")
    nickname = "Kotliner"
    println("Updated Nickname: $nickname")
}

Output:

Language: Kotlin
Version: 1.8
Updated Version: 2.0
Nickname: null
Updated Nickname: Kotliner
