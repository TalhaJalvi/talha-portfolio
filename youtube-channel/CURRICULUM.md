## Rules that protect channel focus

- Use Python in every launch-season tutorial.
- Explain the concept first and syntax second.
- Keep general tech-news videos relevant to programmers, Python, AI, or developer tools.
- Put news into a separate playlist so the learning path remains sequential.
- Delay unrelated Android/Kotlin tutorials until the Python launch season has enough performance data.
