# Talha Jalvi — Developer Portfolio & Engineering Articles

This repository powers Talha Jalvi's portfolio and developer knowledge site.

## Current focus

- Android and Kotlin engineering
- Jetpack Compose
- React Native and mobile systems
- Python backend development
- APIs, databases and real-time systems
- AI engineering and production implementation notes

## SEO/content rules

- Publish only complete, useful pages.
- Do not add empty placeholder HTML files to the sitemap.
- Each indexable article should have a unique title, meta description, canonical URL, H1 and useful internal links.
- Prefer real implementation details, code, architecture decisions, benchmarks and lessons learned over generic summaries.
- Add new finished articles to `tal-sitemap.xml`.

## Domain migration

The site currently uses the GitHub Pages URL. When the custom domain is purchased, update canonical URLs, Open Graph URLs, `robots.txt`, `tal-sitemap.xml` and GitHub Pages custom-domain settings together before the main SEO publishing push.
